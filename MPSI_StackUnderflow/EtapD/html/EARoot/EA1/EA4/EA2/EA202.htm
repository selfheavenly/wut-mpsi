Scenario Type
Basic Path Basic Path
Details:
Steps:
1. Wybiera opcję "Rozpocznij offboarding pracownika"<br/>
2. Wyszukuje pracownika i odpytuje Active Directory o jego status zatrudnienia<br/>
3. Przeszukuje bazę danych i agreguje listę wszystkich urządzeń przypisanych do tego profilu<br/>
4. Wyświetla wygenerowaną kartę obiegową (listę sprzętu do zwrotu)<br/>
5. Weryfikuje i zatwierdza wygenerowaną listę<br/>
6. Zmienia status urządzeń na "Oczekujący na zwrot"<br/>
7. Wysyła powiadomienie e-mail do Pracownika z wykazem sprzętu i terminem zwrotu<br/>
Exceptions:
3a. Brak sprzętu przypisanego do profilu (at End)
Brak sprzętu przypisanego do profilu Alternate
Details:
Steps:
1. Wykrywa, że pracownik nie ma przypisanego żadnego sprzętu<br/>
2. Wyświetla komunikat "Brak zasobów do rozliczenia"<br/>
