Scenario Type
Basic Path Basic Path
Details:
Steps:
1. Wybiera opcję "Nowy wniosek o wypożyczenie"<br/>
2. Odpytuje Active Directory i pobiera dane pracownika oraz identyfikuje jego przełożonego<br/>
3. Wyświetla formularz wniosku z polami: Kategoria sprzętu, Uzasadnienie, Przewidywany okres<br/>
4. Wybiera kategorię (np. Laptop), wpisuje uzasadnienie i zatwierdza formularz<br/>
5. Weryfikuje kompletność danych i poprawność okresu wypożyczenia<br/>
6. Zapisuje wniosek w bazie danych ze statusem "Oczekuje na opinię przełożonego"<br/>
7. Wysyła powiadomienie e-mail do zidentyfikowanego Przełożonego<br/>
Exceptions:
5a. Błąd walidacji danych (at 4)
Błąd walidacji danych Alternate
Details:
Steps:
1. System wyświetla komunikat o błędzie, np. "Pole uzasadnienie jest wymagane"<br/>
2. System podświetla brakujące pola na czerwono<br/>
